# DPI Control

DPI Control — Android-приложение для локального обхода DPI-блокировок без root и без удалённого VPN-сервера.

Приложение использует Android `VpnService`, `hev-socks5-tunnel` и native ByeDPI. Основой служит проверенная стратегия №16 из рабочей версии 0.4; для Meta-сетей добавлена отдельная обработка UDP и нестандартного TCP-трафика.

## Возможности

- локальный DPI bypass через Android `VpnService`;
- проверенная стратегия ByeDPI №16 и каталог альтернативных стратегий;
- обработка TCP/TLS и UDP-трафика;
- дополнительная совместимость для Meta-сетей, используемых Instagram и WhatsApp;
- исключение выбранных Android-приложений из VPN;
- встроенный Telegram WS Proxy;
- тёмный Material 3 интерфейс.

Трафик обрабатывается локально на устройстве. DPI Control не создаёт удалённый VPN-туннель и не требует root-доступа.

Эффективность DPI-обхода зависит от оператора, типа сети и используемых провайдером методов фильтрации.

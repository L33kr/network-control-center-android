# DPI Control

DPI Control — Android-приложение для локального обхода DPI-блокировок без root и без удалённого VPN-сервера.

Приложение использует Android `VpnService`, `hev-socks5-tunnel` и native ByeDPI. Основой служит проверенная стратегия №16 из рабочей версии 0.4.

## Возможности

- локальный DPI bypass через Android `VpnService`;
- проверенная стратегия ByeDPI №16 и каталог альтернативных стратегий;
- обработка TCP/TLS и UDP-трафика;
- отключаемое дополнение для Instagram и WhatsApp и кнопка возврата к чистой №16;
- DNS-каталог из актуального [ZapretGUI](https://git.zapret.moe/zapretdiscordyoutube/zapretgui) и ручной ввод DNS;
- проверка DNS, HTTPS и UDP через ByeDPI с копированием отчёта;
- исключение выбранных Android-приложений из VPN;
- встроенный Telegram WS Proxy;
- тёмный Material 3 интерфейс.

Трафик обрабатывается локально на устройстве. DPI Control не создаёт удалённый VPN-туннель и не требует root-доступа.

Эффективность DPI-обхода зависит от оператора, типа сети и используемых провайдером методов фильтрации.

Для начала запусти VPN с чистой №16. Если нужны дополнительные Meta-правила, выключи VPN, включи переключатель Instagram / WhatsApp и подключись снова. При обновлении с 0.5.3 прежнее поведение сохраняется до изменения переключателя.

«Проверить соединение» проверяет доступ к серверам через локальный SOCKS5. Просмотр видео, медиа и звонки проверяются отдельно в приложениях. Стратегии Windows winws/Lua напрямую не импортируются в ByeDPI.
